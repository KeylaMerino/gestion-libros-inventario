# Gestión de Libros e Inventario

## Sistema
Sistema de gestión para una librería.

## Módulo
Gestión de libros e inventario.

## Stack tecnológico
Python + Django.

## Descripción
El módulo permitirá registrar, consultar, actualizar y eliminar información de los libros disponibles en la librería.

## Requisitos funcionales
- RF-01: Registrar libros.
- RF-02: Consultar libros.
- RF-03: Actualizar información de libros.
- RF-04: Eliminar libros.

## Flujo de trabajo
La rama `main` se mantendrá estable. Para cada cambio se creará una rama de trabajo con el formato `feature/nombre-del-cambio`. Los cambios serán revisados mediante un Pull Request antes de fusionarse con `main`.
